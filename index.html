➜
🐙

➜

➜

Tech Stack

The tools behind this page

Version Control

Git & GitHub

Track every change and keep the code safe in the cloud.

Cloud

AWS EC2

A virtual Ubuntu server running 24/7 with a public IP.

Web Server

Nginx

Fast, lightweight server that delivers the HTML to visitors.

Access

SSH

Secure key based login to manage the server remotely.

Commands I Used

The whole setup, in a nutshell

# on my laptop
$ git add .
$ git commit -m "message"
$ git push -u origin main
# on the server
$ sudo apt install nginx git
$ git clone https://github.com/.../DevOps.git
$ service nginx restart
